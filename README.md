# आर्थिक आधार पर आरक्षण आंदोलन 2026 — Next.js starter

A simple, premium-looking 4-page Next.js website designed for a low-budget first freelance project while leaving room for future expansion.

## Pages

- `/` — Home
- `/praveen-arora` — Praveen Arora
- `/support` — Paytm QR support page
- `/contact` — Third-party contact form

## Setup

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Replace the supplied assets

Put these files inside `public/images/`:

- `hero.jpg` — clean hero image
- `praveen.jpg` — approved portrait
- `poster-1.jpg`
- `poster-2.jpg`
- `poster-3.jpg`
- `poster-4.jpg`

For the support page, replace the placeholder QR with the client's actual Paytm QR.

## Contact form

Replace:

`https://formspree.io/f/YOUR_FORM_ID`

inside `app/contact/page.tsx` with the endpoint from your chosen third-party form service.

## Important

Before publishing, confirm all names, event date/time/location, claims, photographs, payment recipient details and legal/registration information with the client.
